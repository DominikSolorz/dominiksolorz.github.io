# HOME SECURITY / kamera/downloads

Opublikowane instalatory Windows EXE. **Nie przenoś i nie przemianowuj paczek**, bo aktualizator i publiczne linki mogą używać konkretnych nazw.

W katalogu jest 62 opublikowanych plików `.exe` według schematu `HOME-SECURITY-Desktop-Setup-WERSJA.exe`. Numer w nazwie identyfikuje konkretny pakiet, **nie oznacza**, że jest on obecnie używany. Właściwą wersję odczytaj z [manifestu aktualizacji](../desktop-update.json) i [mapy wydań](../../docs/RELEASE-MAP.md).

Przykładowe pliki:

- [`HOME-SECURITY-Desktop-Setup-1.3.0.exe`](HOME-SECURITY-Desktop-Setup-1.3.0.exe)
- [`HOME-SECURITY-Desktop-Setup-1.3.1.exe`](HOME-SECURITY-Desktop-Setup-1.3.1.exe)
- [`HOME-SECURITY-Desktop-Setup-1.3.2.exe`](HOME-SECURITY-Desktop-Setup-1.3.2.exe)
- [`HOME-SECURITY-Desktop-Setup-1.3.3.exe`](HOME-SECURITY-Desktop-Setup-1.3.3.exe)
- [`HOME-SECURITY-Desktop-Setup-1.3.6.exe`](HOME-SECURITY-Desktop-Setup-1.3.6.exe)
- [`HOME-SECURITY-Desktop-Setup-1.4.1.exe`](HOME-SECURITY-Desktop-Setup-1.4.1.exe)

Pełna lista wersji jest widoczna powyżej w przeglądarce GitHub. Nie publikuj nowej wersji przez ręczne podmienienie archiwum.
