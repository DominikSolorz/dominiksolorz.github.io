# HOME SECURITY / kamera/updates

Opublikowane archiwa ZIP aplikacji Windows do aktualizacji i przywracania. **Nie kasuj starych paczek**; mogą być wykorzystywane w procesie rollback.

W katalogu jest 67 opublikowanych plików `.zip` według schematu `HomeSecurityDesktop-WERSJA-win-x64.zip`. Numer w nazwie identyfikuje konkretny pakiet, **nie oznacza**, że jest on obecnie używany. Właściwą wersję odczytaj z [manifestu aktualizacji](../desktop-update.json) i [mapy wydań](../../docs/RELEASE-MAP.md).

Przykładowe pliki:

- [`HomeSecurityDesktop-1.1.0-win-x64.zip`](HomeSecurityDesktop-1.1.0-win-x64.zip)
- [`HomeSecurityDesktop-1.1.1-win-x64.zip`](HomeSecurityDesktop-1.1.1-win-x64.zip)
- [`HomeSecurityDesktop-1.1.2-win-x64.zip`](HomeSecurityDesktop-1.1.2-win-x64.zip)
- [`HomeSecurityDesktop-1.1.3-win-x64.zip`](HomeSecurityDesktop-1.1.3-win-x64.zip)
- [`HomeSecurityDesktop-1.1.4-win-x64.zip`](HomeSecurityDesktop-1.1.4-win-x64.zip)
- [`HomeSecurityDesktop-1.2.0-win-x64.zip`](HomeSecurityDesktop-1.2.0-win-x64.zip)

Pełna lista wersji jest widoczna powyżej w przeglądarce GitHub. Nie publikuj nowej wersji przez ręczne podmienienie archiwum.
