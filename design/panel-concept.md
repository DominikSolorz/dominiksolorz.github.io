# HOME SECURITY — projekt panelu

Wygenerowano narzędziem wbudowanym imagegen. Obraz jest wizualizacją dwóch ekranów, nie zrzutem działającej aplikacji ani dowodem transmisji. Logo referencyjne: kamera/assets/ds-logo.jpg. Przykładowy kadr i dane w makiecie nie są używane jako rzeczywiste dane aplikacji.

## Prompt

Use case ui-mockup. Create one polished high-fidelity UI design board containing TWO desktop HOME SECURITY app screens side by side, labeled PULPIT and USTAWIENIA. Use reference image only as the original DS logo identity: gold crowned shield with scales and DS monogram, small at top left. Do not redesign logo. Premium professional Windows surveillance application in Polish. Matte near-black #09090c, charcoal cards, restrained crimson #dc2944 active accents, white typography and muted rose-gray secondary text. Compact collapsible sidebar: Pulpit, Sterowanie, Archiwum DVR, Ustawienia, Konto, Diagnostyka. Each screen separate content, no stacked unrelated sections. Pulpit screen has a single large realistic unoccupied living-room camera preview, compact live status, no DVR, no Start Stop buttons on dashboard. Settings screen shows category navigation Obraz, Dźwięk, Nagrywanie, Detekcja, Urządzenia, with clean form rows for quality and segment duration, Save and Cancel footer. No fake performance claims, no futuristic ornaments, no neon glow. Clear readable spacing, 16:9 design board landscape, polished restrained enterprise product design. This is a design proposal, not evidence of a running camera.
