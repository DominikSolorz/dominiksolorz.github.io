# HOME SECURITY — projekty nowego wyglądu

Ten katalog jest miejscem na 21 osobnych makiet PNG, 13 referencyjnych plansz JPG oraz pierwotny wzór Aivo. Prace dotyczą **tylko wyglądu**, a nie kodu działającej aplikacji.

**Status:** indeks i miejsce przygotowane; binarne pliki PNG/JPG **nie zostały jeszcze przesłane do GitHuba**. Nie traktuj odnośników do makiet jako gotowych, dopóki pliki nie pojawią się w katalogu.

## Planowana struktura

- `ekrany/` — 21 osobnych ekranów PNG
- `plansze/` — 13 zbiorczych i historycznych projektów JPG
- `referencje/` — zdjęcie inspiracyjne Aivo oraz prototyp demonstracyjny ZIP

## Jak korzystać

Claude projektuje **wyłącznie w `design/`**. Nie nadpisuj istniejących `design/marketing/`, `design/documents/` ani żadnego pliku w `kamera/`. Działające logowanie, PIN, nagrywanie i aktualizacje nie są częścią tych makiet.

Na zdjęciach mogą występować **fikcyjne** kamery, alerty, liczby, opinie klientów, oferty handlowe i odznaki zabezpieczeń. Nie publikuj tych informacji jako prawdziwych danych HOME SECURITY. Teksty polityki prywatności, RODO i regulaminu muszą zostać osobno zweryfikowane przed wdrożeniem.

Paczka lokalna do przeniesienia na tę gałąź: `HOME_SECURITY_DO_GITHUB_DESIGN.zip`. Pliki docelowe wewnątrz archiwum mają ścieżki `design/home-security-redesign/...`. GitHub nie rozpakowuje ZIP automatycznie — prześlij pliki po rozpakowaniu.
