off-white text, thin gray borders, modern Segoe UI-like typography, compact

sidebar with small gold crowned DS shield logo placeholder, Pulpit, Sterowanie,
Nagrania, Ustawienia, Diagnostyka. Gold confined to brand emblem. Native Windows
thin title bar. Realistic readable controls. This is a concept design, put small
'PROJEKT UI' caption, do not imply screenshot of running system. No people,
no private footage. Match common visual language across every screen.

   microphone icon top left, events list on right, compact truthful recording/storage
   status. NO DVR timeline here.

   row, camera and microphone selectors, recording mode cards. Stop zapisu retains

3. Nagrania: large archive playback player, date selector, timeline with thumbnails,
   recording list, right sidebar Miejsce zapisu showing folder nagrania, Wybierz

4. Ustawienia: category rail Obraz, Dźwięk, Nagrywanie, Konto, System. Main section
